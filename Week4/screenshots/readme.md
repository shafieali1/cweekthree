1. Calculate Quality Button
The Calculate Quality button checks the user's salary and years of experience to determine whether the user qualifies for a loan.
Salary must be greater than or equal to 200.
Years of experience must be at least 2 years.
Both values must be positive numbers.
The result is displayed in the Decision Result label.
Example: If the user enters a salary of 300 and 3 years of experience, the program displays: "You qualify for a loan."

2. Change Button Color
The Change Btn Color button changes the background and text colors of the buttons.
BackColor changes the background color.
ForeColor changes the text color.
The Calculate Quality button becomes lime green with white text.
The Change Btn Color button becomes forest green with white text.

3. Exit Button
The Exit button closes the current Windows Forms application window.
